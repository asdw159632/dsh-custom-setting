# 需求文档：侧栏工作区活跃 / 沉默分组

状态：**需求已确认，待实现**
记录日期：2026-10-08
需求编号：`mods/active-workspaces/`

---

## 1. 一句话目标

DSH 左侧栏的「工作区视图」现在把所有工作区平铺在一个列表里，暂时不用的工作区也一直占位。
把它拆成 **活跃工作区** 与 **沉默工作区** 两段，两段都能各自展开 / 收起，让侧栏只突出当前在推进的需求。

## 3. 判定规则（最终口径）

对每一个工作区 W，按下面的顺序判定它落在哪一段：

```
silent(W) =
       （W 被手动钉为沉默，即 pinnedSilentAt(W) 存在）
   且 （W 的活动时间 <= pinnedSilentAt(W)）          // 钉住之后没有新活动
   且 （W 不是当前打开的工作区）
```

* `W 的活动时间` = max(该工作区下所有可见会话的 `updatedAt`)；
  **该工作区一条会话都没有时，取工作区的创建时间**。
* 当前打开的工作区（`containsCurrent`）**永远进活跃区**，优先于钉住与时间判定。
* `silent(W)` 为假 → 进活跃区。
* 手动「恢复」（点太阳）= 删除 `pinnedSilentAt(W)`，回到纯自动判定；
  若 W 本来就已经超过阈值，它会落回沉默区 —— 这是预期行为。
* 阈值默认 `7d`，来自插件配置项（键名实现时定，例如 `silentAfterDays`），
  写在 profile 的 `cordis.patch.yml` 的插件 config 里。

### 空组

* 活跃区为空 → 不渲染活跃段标题。
* 沉默区为空 → 不渲染沉默段标题。

### 段级展开/收起

* 两个段各自有可点击标题行，点击切换展开/收起。
* 默认：活跃段展开、沉默段收起。
* 状态持久化方式与现有侧栏「工作区条目」的展开状态一致。

## 4. 交互细节

* 工作区行 hover 时显示操作区（现有行为：hover 才出现重命名 / 删除 / 新建会话等按钮）。
  在其中**追加一个图标按钮**：
  * 所在段为活跃：图标为月亮，点击 → 钉为沉默（记录当前时间），该工作区立即移入沉默段。
  * 所在段为沉默：图标为太阳，点击 → 取消沉默钉，按 §3 重新判定。
* 按钮需要 `aria-label` 与 tooltip 文案（走插件现有 i18n 机制，中英文都要）。
* 沉默段的行展开后，内部会话列表行为与今天完全一致（会话行、拖拽、溢出「展开更多」都保留）。

## 5. 明确不做的事

* 不新增 DSH 设置页面 / 设置项 UI（阈值只走配置文件）。
* 不改工作区选择弹窗（`WorkspacePicker`）、搜索结果、扁平列表。
* 不给沉默段做灰化、降透明度等视觉弱化。
* 不改工作区的重命名 / 删除 / 拖拽排序等既有能力。

## 8. 验收方式（待用户确认细节）

* 侧栏出现两段标题，活跃展开、沉默收起。
* 沉默段为空时看不到该段。
* 当前工作区永远在活跃段且展开。
* hover 月亮 → 工作区移入沉默段；该工作区产生新活动后自动回到活跃段。
* 超过 7 天无活动的工作区自动落到沉默段；改配置阈值后行为随之变化。
* 重启 / 刷新页面后，段级展开状态保留。
* 搜索结果、扁平列表、工作区选择弹窗行为无变化。
