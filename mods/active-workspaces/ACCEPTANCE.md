## 3. 阈值可配置（默认 7 天）

在客户端 DevTools 控制台里执行，然后刷新页面：

```js
localStorage.setItem('dsh.workspace.silentAfterDays', '3');  // 改成 3 天
```

恢复默认：`localStorage.removeItem('dsh.workspace.silentAfterDays')`

段级折叠状态存在另一个键：`dsh.workspace.sectionExpansion`
（想重置默认展开状态就删掉它）。

## 4. 一个已知的小差异（请确认可接受）

- **钉住按钮的 tooltip 用的是浏览器原生 `title`**，不是官方那种自绘 `Tooltip`。
  原因：每多改一次 asar 就要重写一次（有风险），所以优先选了最小改动。
  文案与 `aria-label` 都在：「标记为沉默工作区 / 恢复为活跃工作区」。
  如果你希望它和官方按钮完全一致，我可以再改一版（需要再写回一次 asar）。
- **当前工作区上的月亮按钮点了没反应**（因为它永远归活跃段，规则优先级最高）。
  两种选择：(a) 保持现状；(b) 在那个按钮上隐藏 / 置灰。你定。
