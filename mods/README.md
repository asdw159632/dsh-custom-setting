# mods —— DSH 客户端定制需求

本目录存放针对 DSH 客户端的各个定制修改，**一个需求一个子目录**。

## 约定

```
mods/
└── <需求名>/
    ├── README.md      # 需求目标、涉及的 DSH 部分、当前状态
    └── ...            # 该需求的源码 / 补丁 / 配置
```

* 需求目录名用简短小写英文 + 连字符，例如 `theme-dark/`、`tool-panel/`。
* 改动只放在自己的需求目录内，避免跨需求互相污染。
* 新增需求后，在 `memory/MEMORY.md` 的目录约定一节按需补充记录。
* 每完成一个阶段，在仓库根目录提交一次 git（并在 `logs/` 写日志）。
